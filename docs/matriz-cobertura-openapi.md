# Matriz de cobertura: flujo a endpoint

Esta matriz deriva operaciones de necesidades funcionales, no de botones ni de tablas. Una misma operación puede alimentar variantes de escritorio y móvil. La columna “Fuente” cita requisitos (`USR`, `ADM`, etc.) y secuencias del repositorio; **no confirma una pantalla de Figma**, porque el prototipo no fue accesible desde este entorno.

Estados: **V** = implementado y verificado; **P** = contrato pendiente, sin ruta funcional.

## Cobertura de Figma pendiente

No se pudo verificar ninguna pantalla, formulario, interacción ni variante responsive del enlace provisto. Para una revisión final deben contrastarse, como mínimo, registro/login, paneles por rol, perfil y cuota del socio, pagos, aptos, escáner QR, sedes, cronograma, entrenadores, eventos, novedades y notificaciones en escritorio y móvil. Cualquier diferencia deberá agregarse a esta matriz sin crear endpoints duplicados por variante visual.
